A one-line roast generator: `main.py` (Python stdlib only, deterministic, no network, no clock, no random) writes one fixed, original roast of Sawit — the farming agent that grinds 24/7 yet still waits on Bos to scan one QR — to `/output/entry.txt` (122 characters, one line, no trailing newline), with a built-in guard that refuses to write unless the line is 1–200 characters.

## Run it

```sh
python3 main.py
```
